2. **"cheapest way to close a limited company" is already held by `/closing-a-limited-company/costs-of-closing-a-company/`** at position ~9.7 (canonical URL row; 1,260 impressions, 3 clicks, 12-mo GSC pull by this critic), with #toc_N fragment rows at 10.6–11.2 splitting the reported average — which is where the foundation's "pos 14.2, no dedicated page" claim went wrong. Consequence: any recommendation that builds a NEW URL on the cost-anxiety/no-money intent is proposing a third-to-fifth page on an intent the site already cannibalises. This is the single biggest correction this critique makes.

## Cross-cutting risks applied to verdicts

- **Gating = ranking destruction.** Two lenses (content-value, defensibility) recommend gating currently-ranking assets (sample letters, Stressed Directors Guide). The monetisation lens itself verified the letters are inline indexable pages and correctly concluded gating "would damage rankings, AEO citability and the generosity signal". Hard gates are killed/stripped; optional email delivery survives.
- **New-URL bias.** Several recs default to new pages where the data shows existing pages already hold the query (close-with-no-money, master closure guide, gazette page into an unconsolidated trio, TTP cluster). Post-collapse, on a domain showing a quality-flavoured devaluation (clicks −89% while positions improved), adding URLs into cannibalised clusters is the riskiest available move; consolidation-first is the only defensible sequence.
- **Stage/variant page splits.** The winding-up "stage-triaged cluster" would create per-stage pages that overlap the existing statutory-demand page (already body-linked from cant-pay-vat) and each other — doorway-pattern risk for a 3,900-impression head term. On-page triage blocks deliver the UX benefit with zero cannibalisation. The single winding-up-order split is the exception: verified distinct intent (hub ranks 44 for it while holding petition terms at 13).
- **Data discrepancies noted but not verdict-changing:** TTP volume/KD cited as 548/KD2 in one rec and 600/KD14 in another (same source era — sloppy, doesn't change the play); winding-up petition position 13 (Ahrefs) vs 35.6 (GSC 6-mo UK) — plausibly index-date and geo differences, but "cheapest head-term win" claims should use the worse number for planning.
- **Fake-signal hygiene.** Blanket "Reviewed on" stamps on 2017–18 news and a retroactive author/reviewer split both trade in manufactured signals. The date-honesty pass reduces algorithm risk; the reviewer split must reflect real sign-off (house rule: never fake authorship) or it becomes the exact YMYL pattern raters are calibrated to catch.
- **JS weight is an algorithm input here.** Mobile Lighthouse ~38, TBT/third-party-JS-bound, 55% of clicks mobile. Dynamic-number-insertion call tracking adds exactly that class of script sitewide. Static per-template numbers first; DNI only if the perf remediation lands headroom.
- **AI-Overview absorption is respected across the set** — no rec proposes definitional expansion; the two production-stop recs are kept. The Q&A long-tail "feed" rec needs a per-question evidence bar so it doesn't become thin-page proliferation wearing a moat costume.

## Verdict rationale details (non-obvious cases only)

- **Gate the sample-letter pack — KILL.** Only distinctive element is the hard gate, which is SEO-negative on ~450 clicks/yr of ranking pages; the salvage (optional "email me this letter") is already the monetisation lens's post-enquiry email rec. A de-fanged duplicate is not worth a slot.
- **Build /liquidation/close-a-company-with-no-money/ — MODIFY.** Falsified premise (see evidence 1–2). Reshape: re-target/upgrade the existing cant-afford-to-liquidate page (title toward the no-money/cheapest intent), concentrate internal anchors on it, de-overlap H2s with costs-of-closing-a-company (which keeps the "cheapest way to close" head), and let the redundancy-funding framing (monetisation rec, kept) do the differentiation. Demand and the Begbies benchmark are real; the new URL is the error.
- **First-Gazette-notice page — MODIFY.** "Nothing to cannibalise" contradicts GSC: three strike-off pages split ~120k impressions, best position 13.8. Ahrefs' "zero strike off keywords" is a top-100 cutoff artefact, not page absence. Sequence: consolidate the trio first (kept content-value rec), then add the gazette-notice page as a child of the survivor. 2,400/mo panic intent justifies the page — only after consolidation.
- **Stage-triaged WUP cluster — MODIFY** to: on-page three-branch triage block + the winding-up-order split page + internal links from HMRC escalation tables. No per-stage URL set (statutory-demand page exists; petition-served/advertised pages would be doorway-thin variants of one journey).
- **Solvent-closure decision layer — MODIFY.** The "master closure guide" already exists: /closing-a-limited-company/ (83k impr, pos 34.1, nav slot). Rebuild it; don't found a competitor to it. MVL-vs-strike-off intent is already crowded by /liquidation/the-difference-between-solvent-and-insolvent-company-liquidation/ (29.6k impr) — repurpose/301 that page into the comparison asset rather than adding a third URL. Calculator: keep, it is the linkable asset the MVL SERP lacks.
- **TTP upgrade (content-value version) — MODIFY** into the seo-strategy optimise-only version (kept): title/H1 alignment + internal links from the cant-pay trio. No TTP cluster build; the page already ranks 7–10 on variants and new siblings would cannibalise it.
- **Emergency tier on WUP pages — MODIFY.** The cluster earned 2 clicks in 6 months; "highest case-value traffic" is potential, not current. Do the zero-build pieces now (kill the mid-page PDF downgrade, callback-promise copy, sticky mobile call bar as a money-template pattern); defer the bespoke petition-date micro-form until the SEO work gives the page visitors to convert.
- **Stop-loss dead ends — MODIFY** on one element: do NOT 301 the typo slug /insolvency/personally-liabilty-of-company-secretary/ now — it holds pos ~9.2 at 2.1% CTR (12-mo); cosmetic slug fixes on ranking URLs are uncompensated risk. Fix at next content rebuild (the content-value lens itself says this; the intent-journeys rec drifted).
- **Feed the Q&A engine — MODIFY.** Protect: unconditional yes (accelerating, AIO-resistant). "Add new questions before any new hub pages" becomes: add only with per-question query evidence, and prefer extending an existing page when volume is tiny — a blanket new-Q&A priority recreates the thin-tail problem the same audit is pruning elsewhere.
- **Split author from reviewer — MODIFY** with the authenticity condition above (real re-review only, forward-looking assignment).
- **Referral partnerships pilot — MODIFY.** PGI introducer with the existing disclosure pattern: acceptable. Personal-debt/IVA referral: park it — monetising consumer-debt referrals on YMYL distress pages, immediately after a quality-flavoured collapse and before the trust layer (authors, standards, reviews) exists, is maximal algorithm risk on the site's best-performing pages.
- **Phone instrumentation (both cro + monetisation versions) — MODIFY** to static per-template numbers first, DNI only post-perf-remediation.
- **Non-Google demand (defensibility) — MODIFY:** strike "gate the guide"; optional email delivery only. Digest + referrer page kept.
- **Ship /data/ hub — KEEP with a hard condition:** 301 the legacy /uk-insolvency-statistics/ (the URL almost certainly holding the pos ~9.4 "insolvency statistics" ranking, 192 internal links) at go-live. Two live duplicates on the only new winning query would be self-inflicted cannibalisation of the flagship strategy.
